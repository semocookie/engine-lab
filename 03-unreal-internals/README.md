## 완료 기준

각 주제의 `README.md`에 **`⚠️ 틀렸던 것`이 채워져 있을 것.**
비어 있다면 이미 알던 것을 확인만 한 것이고, 그건 이 카테고리의 목적이 아니다.

예를 들어 mini-GC를 만들기 전에는 Root Set을 액터 계층 같은 것으로 짐작하기 쉽다.
직접 순회를 짜 보면 그것이 시작점 집합일 뿐 계층 구조와 무관하다는 게 코드에서 드러난다.
**그렇게 드러난 것을 적는 자리가 `틀렸던 것`이다.**

## 실험

- 코드: [main.cpp](main.cpp)
- 결과: [RESULT.md](RESULT.md)
- 측정한 것:
  - 복사가 생기는 자리 — 인자 전달 · 초기화 · 대입 · `push_back`
  - `std::move` 후에도 복사가 세어지는가
  - 값으로 반환할 때의 복사 횟수 (RVO)
  - `auto` 와 `range-for` 가 만드는 복사
  - 람다 캡처 — 값 · 참조 · 이동
  - `vector` 재할당에서 `noexcept` 가 가르는 것
  - (덤) 정적 바인딩 vs 동적 바인딩
